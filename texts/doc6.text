RAG (Retrieval-Augmented Generation) — это архитектурный подход в AI, который объединяет поиск по базе знаний с генерацией текста. Вместо того чтобы полагаться только на знания, заложенные в модель при обучении, RAG-система сначала находит релевантные документы в векторной базе данных, а затем передаёт их как контекст в языковую модель. Это позволяет получать более точные и актуальные ответы. Ключевые компоненты RAG: эмбеддинг-модель для преобразования текста в векторы, векторное хранилище для поиска по сходству и LLM для генерации финального ответа.
