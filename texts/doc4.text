Kotlin — это современный язык программирования, разработанный компанией JetBrains. Он полностью совместим с Java и работает на JVM. С 2019 года Google объявил Kotlin предпочтительным языком для разработки Android-приложений. Kotlin отличается лаконичным синтаксисом, null-безопасностью, поддержкой корутин для асинхронного программирования и расширений функций. Благодаря Kotlin Multiplatform можно писать общий код для Android, iOS, веба и бэкенда. Сообщество Kotlin активно растёт, и всё больше компаний переводят свои проекты с Java на Kotlin.
