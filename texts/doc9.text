Векторные базы данных — это специализированные хранилища, оптимизированные для поиска по сходству в многомерных пространствах. В отличие от реляционных баз, они работают не с точными совпадениями, а с приближёнными ближайшими соседями (ANN). Популярные решения: Pinecone, Weaviate, Milvus, Qdrant и ChromaDB. В простых случаях можно обойтись хранением векторов в памяти и использовать косинусное сходство для поиска. Для RAG-приложений на Kotlin можно реализовать in-memory хранилище с помощью обычного списка эмбеддингов и функции расчёта расстояния между векторами.
