Ollama is a tool that runs large language models and embedding models locally. It provides a simple HTTP API, typically on port 11434. You can pull models such as nomic-embed-text for embeddings or llama3 for chat. Running models locally avoids sending data to external APIs and gives full control over the stack. For Kotlin or any language, you can call the /api/embed endpoint with a JSON body containing the model name and the input text to get embeddings for building RAG or search applications.
