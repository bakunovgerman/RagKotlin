# Правило создания ViewModel

## Общие принципы

1. **ViewModel** должна быть частью уровня представления (presentation layer)
2. Используйте **Koin** для внедрения зависимостей
3. Следуйте принципам **Clean Architecture**: ViewModel не должна знать о деталях реализации Use Cases
4. Используйте **StateFlow** или **SharedFlow** для управления состоянием UI
5. Все операции с данными должны происходить в **корутинах**

## Структура ViewModel

class YourViewModel(
    private val getDataUseCase: GetDataUseCase,
) : BaseViewModel() {

    val uiState: StateFlow<YourFeatureUiState> = _uiState.asStateFlow()

    init {
        getData()
    }

    // Обработка действий пользователя
    fun handleAction(action: YourAction) {
        when (action) {
            is YourAction.Refresh -> loadData()
            is YourAction.SaveData -> saveData(action.data)
        }
    }

    private fun loadData() {
        viewModelScope.launch(Dispatchers.IO) {
             val data = getDataUseCase()
        }
    }
}
